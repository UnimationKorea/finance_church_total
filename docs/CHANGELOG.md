# 변경 이력 (Changelog)

모든 중요한 변경사항이 이 파일에 기록됩니다.

## [1.0.0] - 2024-09-15

### 추가됨 (Added)
- 🎉 새순 교육부 통합 관리 시스템 첫 번째 릴리스
- 🏢 7개 교육부서 선택 시스템 (유아부, 유치부, 유년부, 초등부, 중등부, 고등부, 영어예배부)
- 📊 실시간 대시보드 (수입/지출/잔액/거래건수)
- 💰 회계관리 기능 (거래 추가/수정/삭제)
- 📈 기간별 조회 기능 (이번 달, 분기별, 반년, 1년)
- 📁 파일 관리 (JSON/CSV 백업 및 복원)
- 📋 보고서 기능 (부서별 현황, 최근 거래)
- 🎨 반응형 웹 디자인 (모바일/태블릿/데스크톱)
- 💾 LocalStorage 기반 데이터 저장
- 🔍 거래 검색 및 정렬 기능
- 📊 월별 수입/지출 시각화 차트
- 🖨️ 인쇄 최적화 CSS
- 🌟 Glass morphism 디자인 스타일
- ⚡ 실시간 통계 업데이트
- 📱 터치 친화적 인터페이스

### 기술 스택 (Tech Stack)
- HTML5 시맨틱 마크업
- CSS3 + CSS Variables
- Vanilla JavaScript (ES6+)
- Tailwind CSS 프레임워크
- Chart.js 데이터 시각화
- Font Awesome 아이콘
- PapaParse CSV 처리
- XLSX Excel 파일 처리
- Inter & Noto Sans KR 폰트

### 지원 기능 (Features)
- ✅ 부서별 데이터 분리 관리
- ✅ 실시간 통계 계산
- ✅ 다양한 거래 유형 (수입/지출/예산)
- ✅ 데이터 백업 및 복원
- ✅ 검색 및 필터링
- ✅ 정렬 기능 (날짜/금액)
- ✅ 반응형 디자인
- ✅ 오프라인 사용 가능
- ✅ 데이터 검증
- ✅ 사용자 친화적 UI/UX
