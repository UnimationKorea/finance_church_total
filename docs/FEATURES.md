# 기능 상세 설명

## 🏠 부서 선택 시스템
- 시스템 시작 시 부서 선택 화면 표시
- 7개 교육부서 중 선택 가능
- 선택한 부서의 데이터만 관리
- 언제든지 부서 변경 가능

## 📊 대시보드 기능

### 실시간 통계 카드
- **총 수입**: 선택 기간 동안의 모든 수입 합계
- **총 지출**: 선택 기간 동안의 모든 지출 합계  
- **현재 잔액**: 수입에서 지출을 뺀 순 잔액
- **거래 건수**: 총 거래 건수

### 기간 선택 기능
- **이번 달**: 현재 월의 1일부터 마지막 날까지
- **분기별**: 최근 3개월 데이터
- **반년**: 최근 6개월 데이터
- **올해**: 1월 1일부터 12월 31일까지
- **사용자 정의**: 시작일과 종료일을 직접 선택

### 시각화 차트
- 월별 수입/지출 현황 차트
- 반응형 차트 디자인
- 실시간 데이터 업데이트

## 💰 회계관리 기능

### 거래 추가
- **필수 정보**: 날짜, 구분, 항목, 금액
- **선택 정보**: 담당자, 상세 설명
- **거래 구분**: 수입, 지출, 예산
- **실시간 검증**: 필수 필드 검증

### 거래 목록 관리
- **검색 기능**: 항목명, 담당자명으로 검색
- **필터링**: 거래 유형별 필터
- **정렬 기능**: 날짜, 금액 기준 오름차순/내림차순
- **삭제 기능**: 개별 거래 삭제, 전체 삭제

### 실시간 통계
- **부서별 현황**: 각 부서의 수입/지출/잔액
- **최근 거래**: 최근 5건의 거래 내역
- **월별 차트**: 텍스트 기반 간단 차트

## 📁 파일 관리 기능

### 데이터 백업
- **JSON 백업**: 모든 데이터 포함한 완전 백업
- **CSV 내보내기**: Excel 호환 형식으로 내보내기
- **오프라인 백업**: 브라우저 로컬 저장소에 백업

### 데이터 복원
- **JSON 복원**: 전체 데이터 복원
- **CSV 가져오기**: Excel에서 편집한 데이터 가져오기
- **데이터 검증**: 가져오기 시 데이터 형식 검증

## 📈 보고서 기능

### 재정 요약
- 전체 수입/지출/잔액/거래건수 요약
- 부서별 상세 현황 테이블
- 최근 10건 거래 내역

### 인쇄 기능
- CSS 미디어 쿼리로 인쇄 최적화
- 불필요한 UI 요소 숨김
- 깔끔한 인쇄용 레이아웃

## 🎨 사용자 인터페이스

### 반응형 디자인
- 모바일, 태블릿, 데스크톱 최적화
- Tailwind CSS 기반 유틸리티 클래스
- 터치 친화적 버튼 크기

### 시각적 피드백
- 로딩 인디케이터
- 성공/오류 메시지
- 실시간 데이터 업데이트 표시

### 접근성
- 시맨틱 HTML 구조
- 키보드 내비게이션 지원
- 명확한 라벨과 설명

## 💾 데이터 저장

### LocalStorage 활용
- 클라이언트 사이드 데이터 저장
- 브라우저 세션 유지
- 오프라인 작업 가능

### 데이터 구조
```json
{
  "transactions": [
    {
      "id": "unique-id",
      "date": "2024-01-01",
      "type": "수입",
      "department": "유아부",

      "description": "주일학교 헌금",
```

## 🔒 보안 및 개인정보

### 데이터 보안
- 모든 데이터 로컬 저장
- 외부 서버 전송 없음
- 사용자가 직접 백업/복원 제어

### 개인정보 보호
- 개인 식별 정보 최소 수집
- 담당자명은 선택사항
- 데이터 삭제 권한 사용자에게 있음
