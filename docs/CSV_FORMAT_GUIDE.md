# 📊 CSV 파일 업로드 가이드

새순 교육부 관리 시스템에서 CSV 파일을 업로드할 때 사용할 수 있는 파일 형식에 대한 안내입니다.

## ✅ 지원되는 컬럼 형식

시스템은 **한국어**와 **영어** 컬럼명을 모두 지원합니다.

### 📋 필수 컬럼 (반드시 포함되어야 함)

| 필드 | 한국어 | 영어 | 설명 | 예시 |
|------|--------|------|------|------|
| 날짜 | 날짜, 일자 | date | 거래 날짜 | 2024-09-15 |
| 구분 | 구분, 종류, 타입 | type | 거래 유형 | 수입, 지출, 예산 |
| 항목 | 항목, 내용 | item | 거래 항목 | 교육비, 후원금 등 |
| 금액 | 금액, 액수 | amount | 거래 금액 | 50000 |

### 📝 선택적 컬럼 (생략 가능)

| 필드 | 한국어 | 영어 | 설명 | 예시 |
|------|--------|------|------|------|
| 부서 | 부서, 팀 | department | 담당 부서 | 유아부, 청년부 |
| 담당자 | 담당자, 관리자 | manager | 담당자 이름 | 김교사, 이목사 |
| 적요 | 적요, 메모 | memo | 간단한 메모 | 9월예산, 교재후원 |
| 설명 | 설명, 비고, 상세내용 | description | 자세한 설명 | 성경공부 교재 및 활동지 |

## 📁 CSV 파일 예시

### 🇰🇷 한국어 헤더 예시 (sample_korean_transactions.csv)
```csv
날짜,구분,부서,항목,금액,담당자,적요,설명
2024-09-01,수입,유아부,예산,500000,김교사,9월예산,9월 교육부 예산 배정
2024-09-08,수입,유아부,후원금,100000,이목사,교재후원,교재 구입을 위한 후원금
2024-09-10,지출,유아부,교육비,30000,김교사,교재구입,성경공부 교재 및 활동지
```


## 🎯 거래 구분별 지원 항목

### 📈 수입 (Income)
- 예산
- 후원금
- 특별지원금
- 이월금
- 기타

### 📉 지출 (Expense)  
- 교육비
- 행사비
- 행정비
- 전도비
- 운영비
- 간식비
- 심방비
- 기타

### 💰 예산 (Budget)
- 년간예산 (자동 선택됨)

## ⚠️ 주의사항

1. **인코딩**: UTF-8 또는 EUC-KR 인코딩을 사용하세요
2. **날짜 형식**: YYYY-MM-DD 형식을 권장합니다 (예: 2024-09-15)
3. **금액**: 숫자만 입력하세요 (쉼표 자동 처리)
4. **항목 매핑**: 지정되지 않은 항목은 자동으로 '기타'로 분류됩니다
5. **필수 필드**: 날짜, 구분, 항목, 금액은 반드시 포함되어야 합니다

## 🚨 오류 해결

### "필수 컬럼이 누락되었습니다" 오류
- 헤더 행에 필수 컬럼(날짜, 구분, 항목, 금액)이 모두 포함되어 있는지 확인
- 컬럼명이 지원되는 형식인지 확인 (위 표 참조)

### "처리 가능한 데이터가 없습니다" 오류  
- CSV 파일에 헤더 행과 최소 1개의 데이터 행이 있는지 확인
- 데이터 형식이 올바른지 확인 (특히 날짜와 금액)

### "잘못된 날짜 형식" 오류
- 날짜가 YYYY-MM-DD 또는 다른 표준 형식인지 확인
- Excel에서 저장할 때 날짜 형식이 텍스트로 저장되었는지 확인
